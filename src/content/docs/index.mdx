## How to use this

Pick whatever's relevant to you right now. Each article is self-contained. If you're prepping for interviews, every article ends with an "Interview angles" section covering the questions that actually come up and what a strong answer looks like.

If you want to go deep on one stack, the JavaScript, TypeScript, and React sections build on each other (JS covers the foundations, TS adds the type system, React applies both). The Go section is independent.
